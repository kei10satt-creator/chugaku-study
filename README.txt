高校入試10問 v0.3

変更点
- 正誤を「⭕️ 正解！」「❌ 不正解」で明確表示
- 正解後：自信あった / 迷った
- 不正解後：へぇ！ / どういうこと？
- 理解率＝正解かつ「自信あった」の割合
- MASTER判定も「正解＋自信あった」を別日に2回で成立
- LEVEL 1=300 / LEVEL 2=600 / LEVEL 3=1000 / LEVEL 4=2000 のステージ表示を先行実装
- 2000 MASTERで高校入試 COMPLETE 表示
- MASTER済み問題も低頻度で「今日の10問」に復習出題
- v0.2のlocalStorage記録を引き継ぎ

現在の問題データは300問です。LEVEL 2以降は問題追加時に累積で進行します。

v0.5 expanded explanations update:
- Detailed explanations expanded across all 300 current questions.
- Math explanations include working steps/formulas where useful.
- Science explanations include principles, contrasts, and numerical meaning.
- Social Studies explanations include related people/years/events.
- English explanations include phrase patterns and short examples.
- Japanese explanations include definitions, distinctions, and examples.
