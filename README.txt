高校入試10問 v0.2

GitHub Pages 用の静的Webアプリです。
このフォルダ内の index.html / style.css / app.js / questions.json / manifest.webmanifest を
GitHub リポジトリのルートへアップロードしてください。

v0.2 主な変更
- 初回「今日の10問」の正答率・理解率を公式記録として固定
- 追加学習：もう10問 / 今日の苦手を復習 / MASTER CHALLENGE
- 正解・不正解をシックに強調
- 正解時「完璧 / あてずっぽ」、不正解時「理解できた / まだわからない」
- カレンダーは学習量に応じて1つの炎の温度色が変化
- 日付タップで過去日の記録・総回答履歴を確認
- 回答履歴は「○× + 科目 + 問題文」。タップで答えと解説
- 総学習問題 / 学習日数 / 連続学習 / 最高連続 / MASTER率
- 科目別MASTER率
- MASTER条件：別日に2回「正解 + 完璧」

注意
v0.1 の学習履歴は可能な範囲で自動移行します。
v0.1には「別日に完璧」の日付情報がなかったため、MASTER判定はv0.2以降の記録が中心になります。
